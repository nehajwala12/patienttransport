# Tiger / EMED — NEPTS Sector Intelligence Packet (creditswan.ai) — Rev 6

Static, single-file site. `index.html` is self-contained (inline CSS/JS/SVG; Google Fonts loaded at runtime).

Deploy on Vercel via GitHub: add `index.html` and `README.md` at the repository root → Vercel **Add New → Project → Import** → framework preset **Other**, no build command, root output. Sections are addressable by hash (e.g. `/#decision`, `/#numbers`).

Convention: figures from target systems, licensed datasets, FOI and expert calls are simulated for demonstration and tagged **system · demo** (Appendix §F). Robots: noindex.
